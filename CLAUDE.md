# Rules

## General

1. Before pushing, ask for approval.
2. Upon each pull, read the `.tex` file and make sure everything is correct grammatically.
3. Upon each pull, read the `.tex` file and make sure the math is correct and compiles.
4. Upon each pull, read the `.tex` file and make sure all equations have labels prefixed with `eq:`, and all sections, subsections, subsubsections, and paragraphs are labeled following the cascading convention: `\label{sec:name}`, `\label{subsec:sec-name:subsec-name}`, `\label{subsubsec:sec-name:subsec-name:subsubsec-name}`, `\label{para:sec-name:subsec-name:subsubsec-name:para-name}`.

## Numpy

5. Keep every item in the Numpy section's itemized list to at most 120 characters.
