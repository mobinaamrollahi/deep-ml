\begin{itemize}
    \item \textbf{\texttt{arr.reshape(m, n)}} reshapes without copying; pass \texttt{-1} for one dimension to infer it.

    \item \textbf{\texttt{A @ B}} is the preferred matrix-multiplication operator; \texttt{np.dot} reads worse for 2D.

    \item Broadcasting aligns compatible shapes: \texttt{(m,\,n) - (n,)} subtracts a row vector from every row.

    \item \textbf{\texttt{np.linalg.norm(arr, axis=1, keepdims=True)}} gives row L2 norms; divide \texttt{arr} by it.

    \item \textbf{\texttt{arr[mask]}} selects elements where a boolean array is \texttt{True}; filters rows by a test.

    \item \textbf{\texttt{np.quantile(arr, q)}} returns the q-th quantile; \texttt{np.percentile} takes 0--100 instead.

    \item \textbf{\texttt{np.concatenate([a, b], axis=0)}} joins along an existing axis; \texttt{np.stack} adds one.

    \item \textbf{\texttt{tensor.detach().numpy()}} converts a PyTorch tensor to a NumPy array; call \texttt{.cpu()} first if the tensor lives on a GPU.

    \item Always call \textbf{\texttt{optimizer.zero\_grad()}} before \textbf{\texttt{loss.backward()}}; gradients accumulate by default and will corrupt training if not cleared each step.

    \item Wrap evaluation code in \textbf{\texttt{with torch.no\_grad():}} to disable the autograd engine and reduce memory usage during inference.

    \item \textbf{\texttt{tensor.item()}} extracts a plain Python scalar from a single-element tensor; use it when logging losses to avoid holding the computation graph in memory.

    \item Subclass \textbf{\texttt{nn.Module}}, define layers in \textbf{\texttt{\_\_init\_\_}}, and implement the forward pass in \textbf{\texttt{forward}}; PyTorch then handles parameter registration and gradient flow automatically.

\end{itemize}
